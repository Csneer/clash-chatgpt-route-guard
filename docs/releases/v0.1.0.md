# v0.1.0

首个版本整理了 `clash-guard`、`global-auto`、`global-egress-lock` 三个独立工具及其配置、安装与运维文档，采用 MIT 许可证。

## 获取与安装

发行页提供 GitHub 自动生成的源码压缩包，也可以检出固定版本：

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/Csneer/clash-chatgpt-route-guard.git
cd clash-chatgpt-route-guard
```

按 [README 安装说明](../../README.md#安装) 配置 Linux、Python 3.8+、PyYAML、Mihomo 和所需系统组件；出口绑定还需要 Node.js。Mihomo 本身不随源码包分发。建议先在临时 `DESTDIR` 中演练安装，再配置目标实例。安装器不启用定时器；GLOBAL 伴随服务按各自文档单独启用。

现有使用者升级前应备份本机配置和状态，并停止对应守护器。安装脚本保留已有 `/etc/clash-guard/config.yaml`；需要新增选项时，请对照示例更新自己的配置，不要直接覆盖运行配置。三个入口应分别配置，避免多个守护器同时控制同一选择器。

## 验证范围

- [CI](https://github.com/Csneer/clash-chatgpt-route-guard/actions/workflows/ci.yml) 使用 Ubuntu 24.04 的系统 Python 3.12、PyYAML、Node.js 和 OpenSSL。
- 原生集成测试使用经 SHA-256 校验的 Mihomo `v1.19.33` Linux amd64 compatible 构建；下载版本和摘要固定在工作流中。
- `tests/run.sh` 包含单元测试和三个工具的原生 Mihomo fixture；依赖预检防止 CI 缺少 Mihomo、Node.js 或 OpenSSL。
- 安装检查使用临时 `DESTDIR`，验证四个命令的帮助入口，不修改线上配置、不启动系统服务。

本版本不提供订阅下载器，也不承诺所有代理协议、订阅、旧版 Python 或 Mihomo 的兼容性。原生测试使用本地合成 fixture；真实环境仍需按文档完成 `observe`、显式探测和配置核对后再启用自动模式。
